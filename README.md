# ATELIER — Sitio web

Proyecto web basado en los tres documentos proporcionados:
- ATELIER.docx
- atelier 1.1.docx
- menus.docx

## Estructura
- index.html — Inicio
- empresa.html — Empresa
- publico.html — Público objetivo
- corporativa.html — Identidad corporativa
- visual.html — Identidad visual
- imagen.html — Imagen institucional
- aplicaciones.html — Aplicaciones
- comunicacion.html — Comunicación
- manual.html — Manual de identidad
- mejoras.html — Propuestas de mejora
- Cada menú tiene su propio archivo CSS.
- script.js contiene las interacciones compartidas.

## Interactividad incluida
- Menú responsive para celular.
- Animaciones de entrada al hacer scroll.
- Acordeones en Comunicación.
- Copiado de códigos HEX en Identidad visual.
- Formulario demostrativo.
- Botones y navegación entre páginas.

## Nota
El logotipo se representa aquí con un recurso visual provisional (🦋) porque los documentos aportados describen el imagotipo, pero no entregan un archivo de imagen del logo. Si tienes el PNG/SVG oficial, puede sustituirse fácilmente en el encabezado y pie.
